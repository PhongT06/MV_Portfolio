      Inventory Application

      Must include:

      • Inventory App Repo
      • Purpose/Goals: The Inventory Application was built to recreate a modern full-stack inventory management tool for an e-commerce engineering team. Beyond delivering core CRUD functionality, the project aimed to strengthen full-stack development fundamentals across React, Express, and SQLite/Sequelize. The team collaborated through GitHub PR workflows and followed a user-story-driven, tier-based development structure, gradually expanding functionality while practicing incremental delivery, code reviews, debugging, and iterative improvement. By progressing through these tiers, we implemented key user workflows such as viewing, adding, editing, and deleting items—mirroring real engineering processes and professional full-stack development practices.
      • Overview of Features:
        • Tier I - View All & Single Item View: Displays all items with name, description, price, category, and image; single item pages show full details.
        • Tier II - Add Item: React form with validation; submits POST requests to create new items; instant UI updates and feedback.
        • Tier III - Delete Item: Delete button on item page sends DELETE request to remove an item from the database.
        • Tier IV - Update Item: Pre-filled form for editing items using PATCH requests; front-end and back-end validation included.
        • Additional features: Search bar for filtering items, responsive UI with MUI styling, Parcel bundling for modern dev workflow, seeded database with consistent item data.
      • Your specific contribution in the team:
        • Implemented Tier 1 front-end view for a single item (initial commit)
        • Built Tier 2 "Add item" form and Express route to create items
        • Added Search, Quantity handling, and Validation features
        • Fixed bugs and iterated via several PRs (see PR list below)

        • Full-Stack Development: Built features across React (frontend) and Express/Sequelize (backend) while completing Tier 1-3 functionality.
        • RESTful API Design: Implemented and updated CRUD routes for creating, reading, updating, and deleting items.
        • React Component Development: Created and enhanced components for item details, search, quantity updates, and form workflows.
        • Form Handling & Validation: Added client-side and server-side validation to ensure correct data input and reliable API behavior.
        • State Management: Managed form data, search queries, and UI state with controlled components and React hooks.
        • Database Integration: Worked with Sequelize models and queries to persist and update item records.
        • Debugging & Bug Fixing: Resolved UI issues, validation errors, and API inconsistencies through iterative PRs.
        • Version Control & Collaboration: Used GitHub feature branches and PR reviews to coordinate development.

        • Technical Communication: Wrote clear PR descriptions documenting enhancements and bug fixes.
      • How does this project demonstrate those skills?
        • Situation: Our team was tasked with rebuilding an inventory management system as a full-stack React and Express/Sequelize application. The project required creating a reliable CRUD system, enforcing data integrity, and delivering user-friendly front-end features such as item detail views, search, and form workflows.
        • Task: My responsibility was to implement several core features that connected the front end and back end, including the Add Item and Edit Item flows, quantity handling, search functionality, input validation, and PR-driven iterative improvements. I also needed to ensure that the API behaved correctly, validation rules were enforced, and UI components updated consistently.
        • Action:
          • Built and enhanced React components such as the Single Item View, Add Item form, Edit Item form, and search input using controlled components and React hooks.
          • Implemented POST /items and PUT /items/:id routes, including a reusable server-side validateItem function to enforce correct data types and required fields.
          • Expanded the Sequelize model to include quantity with proper validation, default values, and integration into item creation and updates.
          • Enabled numeric handling by parsing user input (parseInt) and preventing invalid values such as negative quantities or zero/invalid prices.
          • Added search filtering on the client side, allowing users to filter items by name or category.
          • Wrote Jest/Supertest cases to verify success and error cases for item creation and fetching.
          • Delivered changes through clear, incremental PRs focused on features such as validation, quantity, search, and Tier 2 item creation.
        • Result: The application now supports a fully functional full-stack workflow with reliable item creation, updating, validation, and searching. My contributions improved stability, data integrity, and usability across the app. The consistent PR process also strengthened collaboration, maintainability, and code clarity while demonstrating strong full-stack engineering practices.
      • Takeaways:
        • Strengthened full-stack engineering abilities by delivering React front-end features tightly integrated with Express/Sequelize APIs.
        • Gained hands-on experience enforcing data integrity through both client-side and server-side validation patterns.
        • Improved proficiency in React state management, controlled components, and building user-friendly form workflows.
        • Enhanced debugging skills by resolving UI inconsistencies, validation bugs, and API logic issues across the stack.
        • Learned the value of incremental, tier-based feature delivery to maintain code quality and project momentum.
        • Increased confidence writing automated tests using Jest and Supertest to validate API behavior and prevent regressions.
        • Strengthened collaboration and communication by submitting focused PRs, solving merge conflicts, and documenting technical changes clearly.
        • Developed a better understanding of how UX improvements—such as search filtering and clear form validation—impact overall usability.
